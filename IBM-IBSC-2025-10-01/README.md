# IBM Data Science Course - October 2025 Session

This folder contains all course materials, labs, exercises, and resources for the IBM Data Science course session starting October 2025.

## Course Overview

This comprehensive data science course covers the full spectrum of data science skills, from foundational programming concepts to advanced machine learning techniques and capstone projects.

## Module Structure

### Module 01: Data Science Methodology
- Introduction to the data science process
- From requirements to data collection
- Understanding, preparation, modeling, and evaluation
- Live session materials included

### Module 02: Python Fundamentals
- Python basics: Hello World, types, expressions, variables
- String operations
- Data structures: tuples, lists, sets, dictionaries
- Control flow: conditions, loops, functions
- Object-oriented programming: classes and exception handling
- File I/O and data loading with Pandas
- NumPy for numerical computing
- APIs and HTTP requests
- Working with different file types (CSV, JSON, XML, Excel, images, etc.)
- Web scraping introduction

### Module 03: Web Scraping
- Web scraping techniques and best practices
- Review labs and practice exercises
- Final assignments covering library usage and web scraping

### Module 04: Databases and SQL
- SQL fundamentals
- Database operations
- Working with SQLite
- Real-world data practice
- Final database project

### Module 05: Data Analysis and Visualization
- Data analysis techniques
- Visualization tools and libraries
- Multiple practice sessions with datasets
- Live session labs

### Module 06: Data Science Tools
- Advanced data science libraries
- Data manipulation and analysis
- Python scripts and utilities
- JSON data handling
- Live session materials

### Module 07: Statistical Analysis
- Statistical concepts and methods
- Data analysis techniques
- Reference materials and PDFs
- Live session exercises

### Module 08: Machine Learning
- Machine learning fundamentals
- Supervised and unsupervised learning
- Model training and evaluation
- ML study guides (PDFs)
- Multiple practice sessions
- Live session labs

### Module 09: Advanced Topics and Projects
- GitHub instructions and version control
- Advanced data science projects
- Database integration projects
- Final project preparation
- Live session materials

### Module 10: Capstone and Final Projects
- Capstone project resources
- Final assignments
- Project templates and examples
- Live session presentations

## File Organization

- Each module contains numbered subdirectories (e.g., `2.01`, `2.02`) corresponding to specific lessons
- Live session materials are typically in folders named with the module number and "-live-session" suffix
- Practice files, datasets, and resources are included alongside notebooks
- Solutions may be provided in separate files or folders

## Getting Started

1. Navigate to the specific module you're working on
2. Open the Jupyter notebooks in order (they are typically numbered)
3. Follow along with the exercises and complete the practice labs
4. Review live session materials for additional context and solutions

## Prerequisites

- Python 3.x installed
- Jupyter Notebook or JupyterLab
- Required Python libraries (install as needed):
  - pandas
  - numpy
  - matplotlib
  - seaborn
  - scikit-learn
  - requests
  - beautifulsoup4
  - sqlite3 (built-in)

## Notes

- Some modules may reference external datasets or resources
- Live session folders contain both solved and unsolved versions of labs
- Final assignments are typically located in the later modules (3, 4, 9, 10)
