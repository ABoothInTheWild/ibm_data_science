# IBM Data Science Program

This repository contains course materials, labs, exercises, and resources for the IBM Data Science (**IBSC**) and IBM Data Analyst (**IBDA**) courses facilitated by the Head Program Instructor.

## Repository Structure

This repository is organized by class sessions, with each class containing comprehensive modules covering various aspects of data science, from fundamentals to advanced topics.

### Current Classes

Folders are named `IBM-<PROGRAM>-<START_DATE>`, where `IBSC` is the Data Science program and `IBDA` is the Data Analyst program.

* **[IBM-IBSC-2025-10-01](./IBM-IBSC-2025-10-01/)** - Data Science course materials for October 2025 session
* **[IBM-IBSC-2026-01-28](./IBM-IBSC-2026-01-28/)** - Data Science course materials for January 2026 session
* **[IBM-IBDA-2026-04-01](./IBM-IBDA-2026-04-01/)** - Data Analyst course materials for April 2026 session
* **[IBM-IBSC-2026-04-08](./IBM-IBSC-2026-04-08/)** - Data Science course materials for April 2026 session

## Course Content Overview

Each class typically includes modules covering:

* **Module 00**: Orientation and Course Introduction
* **Module 01**: Data Science Methodology and Process
* **Module 02**: Python Fundamentals and Programming
* **Module 03**: Web Scraping and Data Collection
* **Module 04**: Databases and SQL
* **Module 05**: Data Analysis and Visualization
* **Module 06**: Data Science Tools and Libraries
* **Module 07**: Statistical Analysis
* **Module 08**: Machine Learning
* **Module 09**: Advanced Topics and Projects
* **Module 10**: Capstone Projects and Final Assignments

## File Types

* **Jupyter Notebooks** (`.ipynb`) - Interactive lessons, exercises, and labs
* **CSV/Excel Files** - Sample datasets for practice
* **Database Files** (`.db`) - SQLite databases for database exercises
* **Python Scripts** (`.py`) - Standalone Python code examples
* **PDFs** - Study guides and reference materials
* **Other Data Files** - JSON, XML, images, and other formats used in exercises

## Usage

Each class folder contains its own README with specific details about that session's content, schedule, and requirements. Navigate to the specific class folder for detailed information.
